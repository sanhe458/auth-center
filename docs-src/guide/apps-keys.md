# 应用与密钥管理

在[控制台](<AUTH_SERVER>/user/apps.php)管理你的应用和密钥。

## 应用生命周期

| 状态 | 说明 |
|------|------|
| 开发中 | 新创建的应用，仅测试环境可用 |
| 已上线 | 正式环境，所有请求生效 |
| 已吊销 | 应用不可用，所有密钥立即失效 |

## client_id 与 client_secret

- **client_id**：应用公开标识，可以出现在前端
- **client_secret**：应用机密，**只能存在你的后端**，绝不能暴露

### 密钥生成

每个应用可创建多个密钥（最多 5 个有效），支持：

- **按环境区分**：开发 / 测试 / 生产各一把
- **独立吊销**：某个密钥泄露时单独吊销，不影响其他
- **轮换策略**：定期更换，新旧密钥并存过渡

### 密钥安全规则

1. 密钥只显示一次，关闭页面后无法再次查看
2. 泄露后立即吊销并生成新密钥
3. 密钥以 `sk-` 前缀开头，便于识别
4. client_secret 换令牌失败时，先确认是不是用了已吊销的密钥

## 权限范围（Scope）

| Scope | 说明 |
|-------|------|
| `basic` | 头像、昵称、用户 ID、邮箱（默认必选） |
| `netdisk` | 访问网盘文件 |
| `voice` | 调用 TTS / STT 语音服务 |
| `notify` | 发送通知 |

### 权限调整注意

已上线的应用修改权限范围后，**已授权的用户不会自动获得新权限**，需要重新授权。

## 回调地址规范

- 必须与授权请求中的 `redirect_uri` **完全一致**（协议、域名、路径、末尾斜杠都不能差）
- 生产环境必须 HTTPS
- 支持带查询参数的地址，如 `https://yourapp.com/callback?from=login`

## 删除应用

删除应用是**不可逆操作**：

- 所有密钥立即失效
- 所有用户的授权立即撤销
- 所有令牌立即吊销
- 建议先吊销再观察一段时间，确认无影响后删除
